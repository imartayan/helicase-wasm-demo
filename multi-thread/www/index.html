How it works

// Each worker snaps its split points to record starts.
let start = find_record_start_in_window(&window, format);

// A `Read` implementation pulling the worker's range from JavaScript, slice by slice.
let mut parser = FastxParser::<CONFIG>::from_reader(JsFile)?;
while let Some(event) = parser.next() {
    event?;
    lengths.push(parser.get_dna_len());
}
The file is split into one range per Web Worker, each running its own wasm instance and reading its range in 256 KiB slices. Gzip cannot be split, it is decompressed on the fly by a single worker.
