FASTA/FASTQ length statistics computed locally with WebAssembly SIMD. Your file never leaves this page.

How it works

// A `Read` implementation pulling the file from JavaScript, slice by slice.
let mut parser = FastxParser::<CONFIG>::from_reader(JsFile)?;
while let Some(event) = parser.next() {
    event?;
    lengths.push(parser.get_dna_len());
}
Parsing runs in a Web Worker, reading the file in 16 MiB slices with constant memory. Gzip is decompressed on the fly.
